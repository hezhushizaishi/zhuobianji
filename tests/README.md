# 功能检查

统一入口：[scripts/test-app.ps1](../scripts/test-app.ps1)。不指定功能只显示可用组，不构建也不运行；一次可选多个组，共用一次 Release 构建。

    .\scripts\test-app.ps1 -Group collection
    .\scripts\test-app.ps1 -Group storage,close

| 功能组 | 检查内容 |
| --- | --- |
| storage | JSON 往返、副本、替换失败、实例锁、损坏记录、永久删除 |
| basic | 多窗口、保存失败、关闭找回、退出与独立进程恢复 |
| desktop | 桌面挂载、浮窗切换、几何信息与重开 |
| editing | 富文本、Markdown、外观及内容恢复 |
| settings | 默认外观、程序设置与自启 |
| startup | 启动可见状态、透明度与数据入口 |
| window | 移动保存、透明度、自启菜单 |
| lifecycle | 永久删除、关闭、热键生命周期 |
| close | ×、Ctrl+W、找回、主便签关闭与重开 |
| deletion | 删除确认、取消、关框、重复点击与主便签释放 |
| collection | 标签展开收起、独立编辑、取出删除、失败处理与重开 |
| sorting | 标签拖动排序、新建取出删除后的顺序与重开 |
| rail | 标签开关、动画、窗口边界、桌面模式与重开 |
| paste | 自动链接、RTF/HTML 与文字粘贴 |
| layout | 粘贴字体、间距与排版 |
| links | 正文内链接、编辑取消、地址识别 |
| formatting | 三种格式切换、粘贴、回车与重开 |
| preview | 用独立演示便签生成收纳、三种格式、正文链接的真实界面图 |

每次运行写入 .local/checks/app-日期时间，各组单独目录。需要重开的组先写入，再启动另一个进程恢复；两阶段共享该组目录。构建与各阶段输出留在同目录。内部阶段名称只供执行入口使用，日常按功能选组。

storage 不创建窗口；其余组会创建测试窗口。desktop、collection、rail 含原生桌面挂载检查，应在当前登录的真实 Windows 桌面运行；隔离环境缺少 Progman 时不能据此判定程序失败。需要真实桌面或注册表访问时使用相应执行权限。

所有组使用独立 Data；自启检查使用临时注册表键，不改正式 WeNote 启动项。部分组会临时注册测试快捷键，结束后释放；真实占用会导致相关检查失败。正式程序不需要为了这些检查退出。

安装脚本有独立检查，不进入 WPF 检查流程：

    .\scripts\test-install-app.ps1

它使用假 EXE、独立安装目录和临时注册表键，检查 Data/用户文件、自启选择、旧标记迁移、仅保留上一版程序，以及输入复制/EXE 占用失败后的保留和重试；回退也在测试目录，不替换正式程序或淘汰正式回退。

按实际改动选择相关组，必要检查通过即推进，不默认运行全部历史检查。现有检查无需额外测试框架；后续增加检查时归入对应功能。
