# 开发说明

桌边记是 WPF（.NET 10）程序，界面控件用 WPF UI，Markdown 用 Markdig，网页粘贴用 AngleSharp；版本号和依赖版本以 `src/Zhuobianji/Zhuobianji.csproj` 为准。

命名：面向用户一律叫「桌边记」，本地程序是 `桌边记.exe`；代码、工程和命名空间用 `Zhuobianji`。GitHub 发布附件名不支持中文，上传为 `Zhuobianji.exe`。开机启动项的注册表值名沿用早期的 `WeNote`，不要改，否则已开启自启的用户升级后开关会失效。

## 主要流程

**启动**：Program 选定 Data（EXE 旁边，或 `--data-dir`），建立 NoteStore 和 NoteController。Start 加载便签和偏好，先恢复收纳关系，再恢复桌面模式和可见状态；全部隐藏时找回最近一张根便签，普通浮窗前置。

**保存**：正文变化 → NoteWindow.MarkDirty → 400ms 防抖 → SaveNow → Snapshot → NoteStore.Save。拖动、缩放期间暂停写盘，松手后续写。NoteStore 先写临时文件再替换，保留上一版 `.bak`；同一个 Data 只允许一个程序实例写入。

**状态字段**（隐藏、收纳、排序、置顶、桌面模式等）只通过两个入口修改：
- `Update(change)`：改字段并排队保存，用于失败也不影响界面的操作（置顶、显示）。
- `TryCommit(change)`：改字段并立即保存，失败恢复原状态，用于必须落盘才能继续的操作（关闭隐藏、收纳、取出、排序）。

**关闭与删除**：×、Ctrl+W 都是保存并隐藏，保存失败时窗口留在原处并提示重试。主便签关闭时先收起展开的子便签。删除先经 `Dialogs.Confirm`；删除主便签时先把收纳的便签释放到桌面。退出前 FlushAll，任何一张没存上就不退出。

**桌面模式**：DesktopHost 把窗口挂到桌面层，管理父窗口、样式和坐标，挂载失败恢复原状态。这些原生恢复代码有实际用途，不是多余的防御。便签窗口四周留 12px 透明边距画阴影（`NoteWindow.ShadowMargin`，和 NoteWindow.xaml 里 Frame 的 Margin、WindowChrome 的标题高度与缩放边一致），主便签左侧再留 92px 透明标签区；Snapshot 保存的位置和尺寸只算正文卡片，不含这两块。

## 外观怎么改

- 颜色和间距只在 NoteTheme 里改。`ApplyTo` 把配色写成窗口资源键（Surface Header Text Muted Edge Accent Subtle Selected Danger Error），NoteStyles.xaml 和 NoteWindow.xaml 只用 `DynamicResource` 引用这些键，换主题时界面自动跟着变。Subtle、Selected 是正文色加透明度，用作按钮的悬停底和选中底。
- 按钮用两组样式：图标按钮 `IconButton` / `IconToggle`（28×28，平时淡色、悬停变实），文字按钮 `ToolButton` / `ToolToggle`。尺寸、圆角、字号的约定写在 NoteStyles.xaml 开头。
- 动画时长用 `NoteTheme.Fast`（120ms，悬停、淡入）和 `NoteTheme.Standard`（180ms，展开、滑出），缓动用 `NoteTheme.Ease`；系统关闭窗口内动画时时长为 0。只动透明度和位移；资源里的画刷是冻结的，悬停变色靠叠一层底色改透明度。
- 开关型按钮（置顶、源码 / 预览、标签开关、收纳标签）是 ToggleButton，开启时的底色由样式按 `IsChecked` 决定，代码只设置 `IsChecked`。
- 设置、链接和确认框是 WPF UI 控件，深浅色通过 `NoteTheme.ApplyFluent` 跟随便签。
- 富文本存储不写主题值（`FormattedDocuments.SaveRich / LoadRich`）：根上的字体、字号、行高、正文色，以及等于主题色的文字色和链接色都会去掉，读取时按当前主题补上，所以调整主题色后旧便签也会跟随。0.8.x 写进存储的旧主题色列在 `NoteTheme.LegacyText / LegacyLink`，改主题色时这两组旧值保持不动。
- 代码块、行内代码只按显式设置的 Consolas / Courier 识别（`DocumentText.IsCode`），便签字体选 Consolas 不会把正文当代码。

## 构建、安装、发布

需要 Windows 和 [.NET 10 SDK](https://dotnet.microsoft.com/zh-cn/download/dotnet/10.0)（`dotnet` 在 PATH 里）。在项目根目录：

    powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build-app.ps1

输出 `.local/build/current/桌边记.exe`，旁边的 `docs` 里是使用说明和三份第三方许可（许可同时嵌在程序里）。这是自带运行库的 x64 单文件程序，使用者不用装 SDK。构建失败时保留原来的输出。

本地升级：先从托盘退出程序，再运行 `scripts\install-app.ps1`。程序装到项目内的 `桌边记` 文件夹，保留 Data 和自启选择（只有首次安装会开启自启），`archive/rollback` 只留上一版程序。

发布：把构建出的 `桌边记.exe` 以 `Zhuobianji.exe` 的名字上传到 GitHub Release，README 的下载链接指向这个附件名。

脚本里有中文，必须保存为带 BOM 的 UTF-8，否则 Windows PowerShell 5.1 会按 GBK 读错。C# 和 XAML 文件不加 BOM。

## 检查

功能检查是一个自带的控制台程序（`tests/Zhuobianji.Checks`），在真实桌面上开窗口操作，不依赖测试框架。统一入口：

    .\scripts\test-app.ps1                      # 列出功能组
    .\scripts\test-app.ps1 -Group storage,close # 运行指定组
    .\scripts\test-app.ps1 -Group all           # 全部运行，约 1 分钟

| 功能组 | 检查内容 |
| --- | --- |
| storage | JSON 往返、副本、替换失败、实例锁、损坏记录、永久删除（不开窗口） |
| basic | 多窗口、保存失败、关闭找回、退出与重开 |
| desktop | 桌面挂载、浮窗切换、几何信息与重开 |
| editing | 富文本、Markdown、外观及内容恢复 |
| settings | 默认外观、程序设置与自启 |
| startup | 启动可见状态、透明度与数据入口 |
| window | 移动保存、透明度、自启菜单 |
| lifecycle | 永久删除、关闭、热键生命周期 |
| close | ×、Ctrl+W、找回、主便签关闭与重开 |
| deletion | 删除确认、取消、关框、重复点击与主便签释放 |
| collection | 标签展开收起、独立编辑、取出删除、失败处理与重开 |
| sorting | 标签拖动排序、新建取出删除后的顺序与重开 |
| rail | 标签开关、动画、窗口边界、桌面模式与重开 |
| paste | 自动链接、RTF / HTML 与文字粘贴 |
| layout | 粘贴字体、间距、旧数据排版、富文本主题值、Consolas 字体便签 |
| links | 正文内链接、编辑取消、地址识别 |
| formatting | 三种格式切换、粘贴、回车与重开 |
| preview | 生成 README 用的真实界面图，以及排版栏、色块、菜单、深色和屏幕实拍的细节图 |

每次运行写入 `.local/checks/app-日期时间/<组>`。需要验证重开的组会再启动一个进程读取上一阶段的数据。所有组用独立 Data 和临时注册表键（`Software\Zhuobianji.Checks`），不碰正式便签和正式启动项；部分组会临时注册快捷键，被别的程序占用时相关检查会失败。

注意：检查会弹窗、抢前台。同一台机器上同时操作其他窗口时，startup 组的「启动到前台」等检查可能偶发失败，先单独重跑该组再下结论。desktop、collection、rail 需要真实登录桌面（有 Progman）。

安装脚本有单独的检查，不开窗口：`.\scripts\test-install-app.ps1`。它用假 EXE、独立目录和临时注册表键，检查 Data 和用户文件保留、自启选择、只留上一版程序，以及复制失败和 EXE 被占用时的保留与重试。

按改动选相关的组；改动范围大或要发布时再跑全部。
