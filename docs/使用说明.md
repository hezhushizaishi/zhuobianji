# 桌边记

桌边记 1.0.0 · 开源地址 <https://github.com/hezhushizaishi/zhuobianji>

将程序放在一个普通文件夹，双击程序。便签和设置会自动存到程序旁边的 `Data` 中。程序里设置的“关于”页显示版本号，也能打开这份说明。

## 写与读

新建默认用富文本。底部左边的“富文本”按钮可以切换为 Markdown 或纯文本，三种格式各有图标，切换时正文淡入；⋯ 菜单和托盘也能分别新建。顶栏和底栏的按钮都是图标，鼠标停一下会显示名称和快捷键。

- **富文本**：点底部的排版图标，展开加粗、斜体、列表和文字颜色。Enter 分段，Shift+Enter 换行。
- **Markdown**：底部的 `</>` 是源码，眼睛是预览。源码里的 `#`、`**`、链接地址这些符号会淡一些，正文更好读；选中时照常显示。
- **纯文本**：保留原始符号，Enter 直接换行。

文字会自动保存，右下角的淡色小勾表示已保存；保存失败会显示红字，点一下重试。移动和缩放结束后保存位置。Ctrl+Z 撤销，Ctrl+Shift+V 按原文粘贴。

顶栏的图钉把便签置顶（Ctrl+Shift+T），再点一次取消。

整段粘贴时，富文本会识别网页排版、Markdown 和链接，并采用当前便签的字体、字号与间距。网页原来的黑字白底不会带进来，深色便签里照样看得清；标了颜色的字保留。代码里的链接文字保留原样。

切换格式可能丢失部分排版时会先提示。勾选“已知晓，不再提示”并确认后，后续不再询问；设置的“程序”页可以重新开启。

## 链接

富文本和 Markdown 可以直接粘贴带链接的文字，也可以点底部的链接图标插入。选中文字后插入会用这段文字作名称；链接自带的文字（网页里的链接标题、`[名称](地址)`）照样保留。没有名称时自动起名：网址显示域名和路径，太长时省略中间；本地显示文件名或文件夹名。

- 富文本里单击链接只放光标，可以照常修改文字。光标停在链接里时，下方出现卡片，显示完整地址，可以打开、复制地址、修改或取消链接；Esc 收起。
- **Ctrl+单击**直接打开。Markdown 预览里单击即可打开。
- 网站用默认浏览器打开；本地文件打开所在文件夹并选中文件；文件夹直接打开。
- 复制带链接的正文，粘到聊天框、记事本这类只认文字的地方会带上完整地址；粘到 Word 等仍是链接。
- 右键链接也能打开、修改、复制地址或取消链接。

本地完整路径、裸网址和从资源管理器复制的文件，粘贴到富文本会自动变成链接。纯文本保留原文。目标不存在或系统打开失败时，程序会提示。

## 收纳便签

在一张便签的 ⋯ 菜单选择“设为主便签”，再到其他便签选择“收纳到主便签”。目前支持一张主便签、一层收纳。

点左侧标签展开，再点同一标签或子便签的 × 收回。可以同时展开多张，主便签的正文一直保留；标签列最下面的“＋”键直接创建收纳便签。

按住标签上下拖动，其他标签会让出位置，松手即可排序。标签多了放不下时用滚轮上下滚动，最下面的“新建”一直看得到。点主便签顶栏左边的“主便签”可以收起或显示标签栏，收起它不会关闭已经展开的便签。标签的大小跟着主便签走，主便签拉大，标签也跟着变大。

标签右键的“取出”解除收纳，恢复为独立便签。重开程序时，收纳的便签默认收起。顺序和标签开关会记住。

## 贴到桌面

⋯ 菜单的“贴到桌面”把便签贴在桌面上：它待在其他窗口下面，像贴在桌面上的纸条，不能置顶。“恢复普通浮窗”切回来。托盘右键可以一次把全部便签贴到桌面或恢复成浮窗。重开程序后保持原来的样子。

## 关闭与删除

右上角 **×** 或 **Ctrl+W** 保存并关闭。普通便签可从托盘找回，收纳便签回到标签。关闭主便签会先收起展开的子便签，保留收纳关系。

**垃圾桶**、菜单和标签右键的删除都会先确认；确认后永久删除这张便签及其保存副本。删除主便签只删自己，收纳的便签会释放为独立窗口。

## 外观、快捷键与自启

⋯ 或托盘右键可以打开设置，设置窗口出现在便签旁边：点色块换配色，也可以调字体、字号和透明度，改动立刻生效，只改这一张。透明度 100% 不透明，最低 70%：整张便签连字一起变透明，再低就读不清了。

想让所有便签用同一套字体、字号和透明度，在调好的那张便签上点“应用到全部便签”：隐藏的、收在主便签里的也一起改，各自的配色不变。“设为默认外观”只管之后新建的便签。

最上面的“深浅色”管整个程序：浅色、深色或跟随系统，所有便签、左侧标签、弹窗和托盘菜单一起切换；跟随系统时，Windows 换成深色模式，便签马上跟着变。配色仍然每张便签单独选。

字体里的“思源黑体”随程序自带，没装这款字体的电脑也能用。

快捷键在设置中修改：点击输入框，按下组合键，再保存；清空可停用。默认全局快捷键：

- **Ctrl+Alt+N**：新建便签。
- **Ctrl+Alt+空格**：显示／隐藏便签。

托盘右键可开启或关闭开机自启。双击托盘显示便签，鼠标停在托盘图标上会显示版本号；“退出程序”会先保存。

设置的“关于”页：版本号，使用说明、开源地址和下载新版的入口，以及桌边记和随附组件的许可。

## 数据与换电脑

`Data` 保存便签和设置，首次运行时自动创建。设置的“程序”页可以直接打开 `Data`。每张便签是一个 `编号.json`（编号是 32 位字母数字，不带连字符；手改成别的写法的文件不会读入，启动时会提示改回来），设置是 `settings.json`。

**备份**：先从托盘退出程序，再复制整个 `Data`（或整个程序文件夹）。想留下历史版本，就定期这样复制一份。

**副本**：每次保存时，上一次保存的内容留在同名的 `.json.bak` 里。打字时每停顿一下就保存一次，移动、隐藏便签也算保存，所以副本通常只比现在早一步，不能当历史版本用。它的用处是某个文件写坏了、读不了时，还能退回上一次保存的样子。

**某张便签读不了时**，启动时会提示是哪个文件，其他便签照常用，原文件不会被改动。可以这样找回：

1. 从托盘退出程序。
2. 先把整个 `Data` 复制一份留底。
3. 打开 `Data`，把提示里的那个 `编号.json` 改个名字留着，比如改成 `编号.json.坏`。资源管理器默认不显示扩展名，先在“查看”里勾上“文件扩展名”。
4. 把同名的 `编号.json.bak` 改名为 `编号.json`。
5. 重新打开程序，看看这张便签的内容对不对。

**永久删除**会连同副本一起删掉，只能从自己复制的备份里找回。

**升级**：新版在开源地址的 Releases 页面（设置“关于”页的“下载新版”）。先从托盘退出程序，用新下载的程序替换旧的，放在同一个文件夹、文件名不变，`Data` 不用动。换了文件名或位置的话，到设置或托盘里重新打开一次开机自启。

**换电脑**：退出程序后复制整个程序文件夹过去。新电脑无需安装运行库，自启在设置或托盘中重新开启。
