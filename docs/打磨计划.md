# 打磨计划

2026-10-25 定。链接重做已完成（提交 2002971），下一阶段打磨外观和交互。做完一块勾一块，全部做完后删掉本文件，有效内容并入开发说明。

## 目标与边界

- 站长的要求：轻量化是初心，可以引入库但要轻；重点打磨工具排版、弹出的窗口、按钮摆放、多加图标、动画流畅、左侧收纳标签和便签的堆叠。内存和体积现阶段不是重点，但不能太大。
- 护栏：
  - 不引入大型界面框架、浏览器内核。新库只限小而专一，目前只计划 H.NotifyIcon.Wpf（托盘）。
  - 图标用 WPF UI 自带的 Fluent 图标（`ui:SymbolIcon`，现在的垃圾桶就是），不加图标库。动画用 WPF 自带的 Storyboard。
  - 基线：程序 173.5 MB（按 1000 进位是 181.9 MB，同一个数）；11 张便签时独占内存约 141 MB。每块做完看一眼体积，明显上涨要说明。
- 不加新功能（待办清单、选中浮动工具条等记在最后「以后再说」）。
- 站长明确不要对比图：按下面的默认决定直接做，做完给真实截图。

## 默认决定（站长可改）

1. 顶栏按钮一直显示，用淡色图标，悬停变实。不做「悬停才出现」：按钮会跳出来，也不好找。
2. 排版保留底部固定栏，换成图标。不做「选中文字浮出工具条」：会和链接卡片抢位置。
3. 普通便签的顶栏标题留空（只当拖动区）；主便签保留「主便签」，改成小标签样式。
4. 子便签展开时从标签一侧滑出：优先放在主便签左边（标签外侧），顶部对齐该标签；左边放不下再放右边。

## 0. 规范（先做，后面都按它来）✅

写进 `Theme/NoteTheme.cs`（数值）和 `Theme/NoteStyles.xaml`（样式）。

- 图标：统一 `ui:SymbolIcon`，顶栏、底栏、排版栏、菜单都用 20 号图标、显示 16px。图标名以编译为准。
- 按钮分三级：
  - **图标按钮**：28×28，圆角 6，替代现在的 ToolButton 文字按钮。悬停底和选中底改用正文色加透明度（Subtle / Selected），不用 Accent：Accent 是固定的蓝，放在奶油、淡黄、浅绿便签上不协调。
  - **文字按钮**：保留给「富文本 ▾」这类必须带字的。
  - **主按钮**：Accent 实底，只用于弹窗里的确认。放到第 2 块和弹窗一起做。
- 字号：说明文字 11，按钮和菜单 12，正文由设置决定。
- 间距 4 / 8 / 12 / 16；圆角：按钮 6，卡片和弹窗 8，便签 10。
- 动画时长：快 120ms（悬停、淡入），标准 180ms（展开、滑出），一律 CubicEase EaseOut。只动 Opacity 和 RenderTransform；`SystemParameters.ClientAreaAnimation` 关闭时不播。
- 悬停变色要有过渡：在模板里叠一层 Accent 底，动它的 Opacity。资源里的画刷是冻结的，不能直接做颜色动画。

## 1. 便签窗口（`Notes/NoteWindow.xaml`、`NoteWindow.Collection.cs`、`NoteWindow.Saving.cs`）✅

完成情况（2026-10-26）：
- 按下面做了：顶栏、⋯ 菜单、底栏、排版栏全部换成图标；普通便签不写标题，主便签显示「主便签」小标签；顶栏分隔线去掉；保存状态改成淡色小勾，失败显示红字；排版栏做成浅底托盘，分三组；文字颜色改成一排色块，图标下的色条显示选中文字的颜色；排版栏展开时淡入加上移。
- 另外加了：编辑区、源码、预览的细滚动条；右下角缩放角改成两道淡色斜线；编辑区和链接的右键菜单也加了图标；窗口开了布局取整（UseLayoutRounding），边框更利落。
- 阴影：窗口四周留 12 透明边距，卡片背后单独一层 DropShadowEffect，外层缓存成位图，打字不重算。保存的位置尺寸仍只算卡片，老数据打开后卡片位置不变。
- 文字清晰度：顶栏、底栏、排版栏、菜单的小字已经是 ClearType（屏幕实拍测了彩边）。正文还是灰度：在编辑框、滚动区上加 ClearTypeHint、固定 TextHintingMode、布局取整都试过，无效，留到第 4 块再查。
- 与计划不同：排版栏收起不做动画，直接收（收起时正文区要立刻变高，动画反而拖沓）；悬停和选中底用 Subtle / Selected，不用 Accent（见第 0 块）。
- 暂时的副作用：子便签展开时和主便签之间的空隙从 10 变成 34（多了两边的阴影边距），第 3 块重做展开位置时一起改。
- 体积 173.5 MB，没有变化。

**顶栏**
- 现状：「标签」「置顶」是 11 号字，「＋ ⋯ ×」是 20 号符号，大小和基线不齐；每张便签都写着「桌边记」（`HeaderLabel`）。
- 改：
  - 换成同尺寸图标按钮：标签开关 PanelLeft；新建 Add；置顶 Pin / PinOff（ToggleButton）；更多 MoreHorizontal；关闭 Dismiss。
  - 提示文字保留快捷键说明。

  - 顶栏和正文之间的分隔线减弱或去掉，色差保留。
- ⋯ 菜单每项加图标：新建三种（Document / Markdown / TextT）、设置（Settings）、设为主便签 / 收纳、贴到桌面 / 恢复浮窗（Desktop / Window）、显示所有、关闭（Dismiss）、删除（Delete，已有）、退出（Power）。

**底栏**
- 现状是「富文本 ▾、排版、链接、已保存、垃圾桶、缩放角」六样，大多是字。
- 改：
  - 格式按钮保留文字，▾ 换成 ChevronDown 图标。
  - 排版改成图标开关（TextEditStyle，展开时保持选中）。
  - 链接改成 Link 图标。
  - Markdown 的源码 / 预览改成两个图标开关（Code / Eye）。
- 「已保存」：平时不显示字，只留一个很淡的小勾或干脆隐藏；保存中淡显；失败时保留红字「保存失败 · 点击重试」。状态文字放进提示，供检查读取。
- 垃圾桶留在原处（有确认框兜底），缩放角的点调淡。

**排版栏**
- 现状：「B I U S、• 列表、1. 列表、A ▾」全是用字母拼的。
- 改：
  - 换成 TextBold、TextItalic、TextUnderline、TextStrikethrough、TextBulletListLtr、TextNumberListLtr、TextColor 图标。
  - 按「字形 | 列表 | 颜色」分组，组间留细分隔。
  - 文字颜色菜单改成色块，当前颜色在图标下方显示一条色条。
  - 展开和收起：淡入加上移 6px，180ms。

**边缘与文字**
- 阴影：现在只有 1px 描边，加一层柔和阴影。
  - 不能用整窗口的 DropShadowEffect，那样打字时每次都整窗重绘。要用几层半透明 Border 叠出来。
  - 窗口要留出阴影边距。注意桌面模式的坐标，以及 Snapshot 只保存正文卡片的位置和宽度（见开发说明「桌面模式」），标签区的 92px 也要一起算。
- 文字清晰度：透明窗口默认只能灰度抗锯齿。在不透明的 NoteCard 上设 `RenderOptions.ClearTypeHint="Enabled"`，小字号的界面文字试 `TextOptions.TextFormattingMode="Display"`，前后截图对比清晰度。

## 2. 弹窗与托盘（`Dialogs/`、`Shell/TrayMenu.cs`）

- 现状有三套外观：
  - `Dialogs.Show` 用系统 MessageBox；
  - 确认框、链接窗口、设置窗口是 WPF UI 的白底 Win11 样式，跟便签配色无关，「确定」和「取消」长得一样；
  - 托盘是 WinForms 菜单。
- 统一弹窗外壳：
  - 底色跟随所在便签的配色（Surface / Header），主按钮用 Accent 实底，次按钮描边；
  - 出现时淡入并从 0.97 放大到 1，用 120ms；
  - 位置贴近所属便签。
- `Dialogs.Show` 改用同一外壳（WPF UI MessageBox 或自建一个小窗口，选简单的）。
- 链接窗口：
  - 「确定」设为主按钮；
  - 选文件、选文件夹做成带图标的小按钮，放在地址框右侧；
  - 名称框用占位提示，代替现在的悬停提示。
- 设置窗口：
  - 改为在所属便签附近打开，现在是屏幕居中；
  - 配色下拉框改成 6 个色块；
  - 其余版面按规范调整间距。
- 托盘：
  - 换成 H.NotifyIcon.Wpf，菜单用 WPF ContextMenu，和便签菜单同一样式并带图标；
  - 去掉 `UseWindowsForms` 和 `System.Drawing.Icon` 的使用；
  - 做完量一下体积变化。
- 顺手修（清单第 1 条）：Markdown 转富文本和粘贴时写死的代码底色（theme.Code）、引用文字色（Muted）、表格和分隔线边框（Border），在深色下不跟着变。修法同正文色：`NoteEditor.ApplyAppearance` 一并替换，`SaveRich` 不存。
- 顺手测（清单第 2 条）：网页粘贴的 color 样式在深色便签里会不会黑字压深底。属实就把近黑、近白的颜色改成跟随主题，用户自选的颜色保留。
